## Birds vs. Drones
This project is an image-classification project using ANN and CNN in order to see which classification model has the highest precision, when detecting a drone compared to a bird. The purpose was to see how well either of these models could be fine turned in order to increase their prediction ratio. The main objective for the project was to decrease the number of drones being detected as birds. 

## NFL data 
This project is related to importing and working with the NFLReadpy library, which contains relevant data for NFL teams from the last 10+ years.
Using the EPA column which measures the exepected points after the play. Since every offense is given an expected number of it points it is likely to score on that drive based on several factors such as down, distances and so forth. EPA tells wehtehr the play "helped" or "hurted" the offense and by how much. EPA comes from a historical regression model trained on thousands of NFL plays, which increaes its bais, but for this project it seemed suitable.
